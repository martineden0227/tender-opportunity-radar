# 示例产物

`pool_sample.csv` —— 候选池的输出格式示例。

**注意：这是用内置「合成样例」生成的，内容为示意数据，不是真实公告。**
生成命令：

```bash
tender-notice demo --output examples/pool_sample.csv
```

真实采集请按 README 的快速开始执行；真实产物默认被 `.gitignore` 排除，
不会进入版本库（采集数据可能含第三方站点内容，不宜随代码分发）。

## 字段速览

| 列 | 示例值 | 说明 |
|---|---|---|
| 成熟度 | `机会级` | 招标公告属机会级；招标计划属线索级 |
| 标段／招标内容 | `列表页未列明，需点入详情确认` | 列表页确实不提供，**不是采集失败** |
| 投标截止 | `以平台日程安排为准` | 同上，属**字段级说明，不是缺件** |
| 总判定 | `待确认` | 资格核验需投标方自身材料，未提供前不得判为合格 |
| 备注 | `发布时间=…；公告类型=…` | 附加信息写在这里，不新增列 |
